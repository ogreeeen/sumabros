# オートスターブラザーズ

キャラを選択肢から設計すると、あとは自動で戦って決着がつく対戦ゲーム。1試合は4人まで、5〜16人はトーナメント。声は「なし／男性／女性／録音」から選べる。録音は攻撃のセリフだけで、必殺・やられたのセリフは声の高さに合わせて自動でしゃべる。
ダメージ％がたまるほど遠くへふっとび、場外に出るとストックが減る。最後まで残った人の勝ち。
